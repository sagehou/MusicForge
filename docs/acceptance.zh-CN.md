## 验证量与改动相称

Go race／集成／vet、真实应用浏览器和 rclone 验收分为独立任务。后两者复用同一次运行已测试的应用与媒体工具；重试其一不重跑成功的 Go 测试。完整验证仍要求这些任务全部通过。

文档检查链接、一致性和空白；展示改动运行前端类型检查／构建、相关已有浏览器用例和代表性截图。功能、后端、依赖、部署、工作流、测试配置或不确定改动运行完整适用验收。比较范围包含所有未发布工作，不只看最后一个提交。

同仓库可信 push／dispatch 的成功证据，可在七天和环境约束内覆盖相同输入或未改变的继承工作，PR／fork 证据不能复用。`rollback-scope` 记录基线、所选检查与复用 run，`validation-evidence` 保存成功的应用证据，浏览器产物保留截图。仅版本标签变化不必重放相同应用验收；每次发布仍需当次审计、两个最终原生镜像检查和必要回滚。不能手动绕过失败门槛。

## 仍需在你的环境确认

CI 使用 Lidarr 载荷夹具和签名 OIDC 测试提供方，不运行完整 Lidarr 或生产 Authentik。在线歌词和封面搜索使用模拟响应保证测试稳定；上游可用性、地区限制、账号状态及某首歌是否匹配，需要实际使用确认。Navidrome 和 rclone 使用真实服务验证。

Chromium 覆盖应用，WebKit 仅针对手机试听，其他浏览器／平台组合未全面认证。5,000 首曲目的 API 夹具和远程停滞检查用于防回归，不是大规模音乐库容量保证。浏览按页返回 50 个条目，并支持条件请求和变化条目刷新；数据库变化后仍重建服务端内存索引，打开维护工作台仍加载当前完整范围。

存储要满足[部署要求](deployment.zh-CN.md)。普通扫描信任大小／修改时间；修改内容却保留两者时，请完整校验。同 schema 兼容不会恢复已搬迁、替换或删除的文件，完整回滚需要同一停机时点的配置／输出快照。接入全库前请先完成[小规模部署试用](deployment.zh-CN.md#在你的环境试一遍)。
