# Instrument Serif 字体素材

MusicForge 自托管 Instrument Serif 常规体（400），用于拉丁文字标题及完成度展示。中文使用系统衬线字体回退。素材随站点提供，不在运行时请求 Google Fonts。

字体作者为 The Instrument Serif Project Authors，原始项目见 [Instrument/instrument-serif](https://github.com/Instrument/instrument-serif)。字体按 SIL Open Font License 1.1 分发，站点包含[完整许可证与版权声明](../web/public/fonts/InstrumentSerif-OFL.txt)。
