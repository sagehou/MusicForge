## 视觉方向

借鉴 Apple Music 的清晰排版、Navidrome 的媒体浏览密度和专业音频工具的参数对齐。主体使用同一画布，以标题、间距和分隔线组织内容；概览指标、任务、设置、播放器与歌词列表减少外框、嵌套卡片和装饰阴影。封面保留圆角；浮层、焦点、选中和危险状态保留明确边界。

| 项目 | 浅色 | 深色 |
| --- | --- | --- |
| 画布 | `#fbfbfc` | `#111214` |
| 浮层／侧栏表面 | `#ffffff` | `#17181b` |
| 次级表面 | `#f1f2f4` | `#202125` |
| 分隔线 | `#e5e6ea` | `#2b2d33` |
| 正文 | 13px，系统字体 | 同左 |
| 主标题 | 18px／600 | 同左 |
| 数字与音频参数 | 等宽数字，参数使用等宽字体 | 同左 |

保留既有调色板、自定义配色及对比度计算，不更改默认偏好或保存格式。强调色用于主操作、当前导航、选中和播放行；成功、警告和失败继续使用各自语义颜色。

## 侧栏与导航

保留概览、音乐库、任务、设置四个主要入口，其下增加两组现有功能的快捷入口：

| 分组 | 入口 | 现有目标 |
| --- | --- | --- |
| 浏览 | 专辑 | `/library?view=albums` |
| 浏览 | 全部歌曲 | `/library?view=tracks` |
| 浏览 | 全部歌手 | `/library?view=artists` |
| 管理 | 待确认歌词 | `/library?view=tracks&lyrics=needs_review` |
| 管理 | 歌词设置 | `/settings?section=lyrics` |
| 管理 | 编码配置 | `/settings?section=encoding` |
| 管理 | 集成 | `/settings?section=integrations` |

快捷入口复用已有导航和页面参数，不增加功能、API 请求或持久化状态。设置分类切换继续保留表单草稿。主导航表示当前位置，快捷入口不制造第二个选中位置。

桌面侧栏中部可独立滚动，品牌与账户保持可见；分组间距适度，不将少量入口拉满整屏。折叠后保留图标、可访问名称和悬停提示。

## 页面细节

- 概览：指标使用并排数字和细分隔线，近期任务与存储信息沿共同网格对齐；后台存储检查继续在固定区域展示。
- 音乐库：浏览维度、搜索和维护工具自然分层；取消工具栏外卡片，保留筛选浮层、选择状态及批量操作提示。曲目保留时长、音频规格、源／产物大小、音频和歌词状态。
- 详情与试听：行内试听使用透明表面和单行标题，桌面播放控制与歌词并排，窄屏上下排列；圆形播放键与细进度条保持清晰触控目标。歌词区域收敛高度，保留进度滑块、当前歌词高亮、逐行定位与独立滚动。
- 手机曲目：歌名旁紧邻试听键，歌手／专辑作为次级信息；规格和码率沿整行排列，时长与标注“源／产物”的大小紧凑并列。下方状态与歌词操作共享一行，长状态允许自然换行；保留所有参数和现有操作，不为复选框留下贯穿整首歌曲的空缩进。
- 歌词选择：候选采用平整列表、选中强调线和单选框；预览正文减少嵌套边框，保存和下一首操作保持清晰。手机独立页面保留候选与预览分区滚动。
- 任务：任务行使用分隔线；运行中任务依靠进度与状态强调，避免卡片套卡片。
- 设置：分类与表单组成连续工作区，字段间距、帮助文本、校验和保存／放弃工具条沿用现有行为。

## 自适应与可访问性

- `>800px`：236px 侧栏，手动折叠为 76px；桌面列表保持合理密度。
- `601–800px`：72px 图标轨，设置和较宽内容按既有规则收敛。
- `≤600px`：四项底部导航；新增快捷组不进入底栏，原页面内的对应入口继续可用。
- 表格在 `≤1100px` 沿用纵向曲目排布，参数以带说明的事实呈现，不因窄屏而删除。
- 覆盖 1440、900／768、390 和 320px；中英文长标题、路径和 SHA-256 允许换行。
- 保留键盘导航、焦点环、Escape 关闭和焦点恢复、触控目标、安全区、减少动态效果与强制颜色模式。

## 兼容与验收

以已发布 `v0.2.49`（`9bda987`）为兼容基线。保留已发布样式中的共用表单、任务状态、行内详情、移动端歌词与试听规则，集中修改视觉声明，避免样式整理时丢失行为保障。

不改后端、依赖、认证、歌词维护规则、Settings JSON、浏览器存储、任务或 schema 2。新增快捷入口改变 JSX 结构，按仓库的保守门禁由 GitHub Actions 决定完整验收，不手动绕过分类。

本地只做源码、链接和空白检查。构建、类型检查、浏览器检查、审计及门禁选中的其他验证全部在 GitHub Actions 执行。重点复用 `appearance`、`workspace-layout`、`ui-refinement`、`artifact-audition`、`lyrics-mobile`、`library-comparison` 和 `cleanup-and-ui` 的现有检查及截图；以实际 CI 结果为准。

本轮对齐将选择当前页、封面密度、视图切换和高级维护移入视图选项，批量操作仍在选择后出现；歌词填充入口收在歌词维护展开区。文件核对展开时使用完整工作区，保留原有查询、筛选、目录重扫与索引说明。设置导航在窄屏变为横向标签，并同步 ARIA 方向。

歌词选择的强制重搜保留在“搜索选项与匹配说明”中，手机搜索框与普通搜索并排；短屏为候选列表保留至少 96px，并继续独立滚动。中文标题允许字体合成粗体，与确认稿的字重保持一致。

CI 对固定稿与实际页面的标题、工具栏、试听布局、控件、当前歌词、设置网格进行独立几何与样式比较，并保存同视口对照截图。已有播放、拖动、歌词定位、批量操作、草稿、键盘及手机独立滚动检查继续执行。

## Antigravity 细节修订（2026-10-28）

本次按已确认的排版、灰底、线条与圆角建议修订实现，原始 HTML 基准及其哈希保持不变。修订范围如下；其他参考布局与交互约束继续沿用。

- 音乐库和任务筛选去掉外层灰底托盘，保留选中项强调底色、原有尺寸和手机 40px 操作高度。
- 封面网格隐藏重复的正常状态标记，完整状态仍供辅助技术读取。异常使用 12px 单行短文字与语义颜色，封面悬停提示保留完整名称；不只靠颜色区分。短标签位于封面左下，与左上选择框分开，覆盖手机最小封面密度。列表和歌曲详情继续显示完整状态。
- 封面只保留交互容器的一层描边和 8px 裁切，保留选中环及键盘焦点。分页取消独立外框；视图选项等浮层统一为 8px，按钮 6px、微型标签 4px、结构边界 0px。播放圆键、开关和进度条保持其形态。
- 设置开关行去掉整块灰底，标签沿表单左边线对齐，说明紧随开关行；未修改时保存按钮使用中性底色。保存、放弃、草稿与底部导航避让行为不变。
- 封面辅助信息和设置帮助文字收敛至 12px／18px。任务自然语言说明使用系统字体，文件计数与百分比保留等宽数字；完整音频参数和桌面两行密度继续保留。

验收复用现有浏览器用例，保留固定参考的几何、圆角、内边距和试听比较，仅把已批准去掉的导航托盘底色改为独立断言，并继续比较选中项样式。现有网格密度、异常状态可读性、辅助技术文本、选择与导航、短屏设置保存及任务操作检查一起执行；新增截图包含 320px 最小封面密度的中英文与明暗代表。

歌曲详情的后续密度调整：标题与歌名单行并列，收紧标题区上下内边距；过长歌名在标题栏省略，详情正文仍保留全文。专辑曲目不再强制把音频规格独占一行，宽屏将规格、码率、源／产物大小自然并列，窄屏允许码率与容量共用下一行，避免内部容器把常规参数拆成三行；不隐藏参数或缩小字号，保留上下曲、关闭、键盘和焦点恢复。
