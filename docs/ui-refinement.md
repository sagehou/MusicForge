# MusicForge UI · Studio

Monograph 是 Studio 的第二轮精修：以深暖炭导航、纸白画布、自托管 Instrument Serif 标题、标尺式进度与档案分隔线形成统一识别。封面、实际完成度和任务是页面主体。当前实现以 [样式源文件](../web/src/style.css) 和 GitHub Actions 的实际页面截图为准。[Flat Studio 预览](ui-refinement-preview.html) 保留为历史设计资料。

参考 [RCA Records 的 Awwwards 获奖页面](https://www.awwwards.com/sites/rca-records)、[Webby 最佳用户界面案例](https://www.webbyawards.com/crafted-with-code/rca-records/)与 [FWA Because Recollection 年度案例](https://thefwa.com/article/fwa-site-of-the-year-2015)，提取字体识别、内容主导和细节反馈的原则。这里的交互服务于库维护与试听，设计判断以实际工作区的可读性和操作效率为准。

强调色沿用现有调色板及自定义配色，按钮文字与强调文字继续计算对比度。导航使用独立的高对比文字、选中表面和信号标记。成功、警告、失败保留文字或图标说明；表格数字等宽对齐，音频参数、路径与诊断使用等宽字体。两个同源 WOFF2 字体共 32,636 字节，不请求外部字体服务，见[字体许可与来源](font-assets.md)。

## 页面与导航

- 桌面侧栏宽 232px，折叠后 76px；601–800px 使用 72px 图标轨；600px 以下保留四项底部导航。快捷入口复用现有 URL，侧栏中部独立滚动，品牌与账户保持可见。
- 标题与操作位于统一的画布标题栏，语言、主题与配色仍在右上角展开。音乐库浏览切换采用强调色下划线，与搜索和视图选项保持清晰分组；桌面搜索使用受限宽度，窄屏占满可用空间。
- 概览四个指标使用上下横线及内部竖线，800px 以下变为两列。放大的实际完成度和带刻度的进度条建立主次；活动曲目、歌词覆盖和存储路径使用分隔线减少嵌套边框。近期任务仍为紧凑列表，存储检查与离线提示留在存储面板。
- 任务采用紧凑列表，运行中任务突出进度，详情在原行下展开为内嵌检查区，保留结果、日志、分页、筛选和任务控制。
- 专辑、歌手封面保持无外框的网格结构，标准密度使用 22px 行间距；缺图沿用原图标并增加克制的唱片纹理。异常短标签在封面左下，完整状态供辅助技术读取；最小密度下仍保持可读，选择框与标签不重叠。
- 歌曲行继续展示时长、音频规格、码率、源／产物大小、音频与歌词状态。完整路径、哈希与标签留在行内详情；标题区收紧并省略长歌名，详情正文保留全文。
- 试听使用内嵌播放器，桌面控制与歌词并排，窄屏上下排列。保留实际音频播放、进度滑块、歌词定位、当前行跟随及独立歌词滚动。
- 歌词候选与预览分栏，手机独立页面保留候选与预览分区滚动。短屏限制搜索说明高度，为候选保留至少 96px，并让预览与保存操作始终可达。
- 设置分类和表单使用表面面板。窄屏分类横向排列，字段上下堆叠；草稿、校验、保存与放弃行为沿用原有实现。保存栏显示在底部导航上方。

## 可访问性与兼容

保留键盘访问、焦点环、Escape 关闭与焦点恢复、单选及部分选择状态、减少动态效果、强制颜色模式和安全区。手机歌曲、歌词、详情与保存操作至少保留 40px 触控高度，文本输入使用 16px 字体以避免自动缩放。

封面在精细指针悬停或键盘焦点进入时轻抬 3px，图像轻微放大，保留原色；共享封面过渡为 360ms。菜单展开采用 180ms 短入场，行内检查区采用 220ms 入场，库导航下划线沿起点展开。按钮按下移动 1px 并轻缩，主操作悬停增加短阴影。所有反馈遵循减少动态效果；轮询不重复播放入场动效。

以已发布 `v0.2.53`（`b2802b9`）为兼容基线。本轮不修改依赖、API、认证、Settings JSON、浏览器存储、歌词维护规则、任务格式或 schema 2。字体与图标资源仍按仓库的保守分类器选择完整验收。

## 验收

本地只做源码、文档链接及空白检查。安装、类型检查、构建、浏览器验证、安全审计及其他选中门禁全部在 GitHub Actions 执行，不手动覆盖 CI 分类。

复用现有外观、工作区、试听、歌词、音乐库、任务和设置检查，保留密度、音频、触控、焦点、草稿、会话恢复及分页保证。删除仅针对历史预览的样式比较，将重复视口／语言／主题组合缩减为桌面、平板与窄屏代表场景，并保存实际页面截图供人工复核。
