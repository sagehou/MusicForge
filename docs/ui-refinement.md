# MusicForge UI · Studio

本轮采用高级简约的圆角毛玻璃（Rounded Glassmorphism）视觉设计：环境感画布、半透明毛玻璃分层表面（`backdrop-filter: blur(20px) saturate(180%)`）、精细微光描边、胶囊化浮动交互栏与多层级圆角。当前实现以 [样式源文件](../web/src/style.css) 和 GitHub Actions 的实际页面截图为准。[Flat Studio 预览](ui-refinement-preview.html) 保留为历史设计资料，不再作为本轮像素对照基准。

## 视觉规则

| 项目 | 浅色 | 深色 |
| --- | --- | --- |
| 画布 | `#f8f9fa`（带柔和双色径向氛围光） | `#0b0c0e`（带深色微光径向氛围） |
| 毛玻璃主要表面 | `rgba(255, 255, 255, 0.76)` | `rgba(18, 19, 23, 0.72)` |
| 毛玻璃浮动表面 | `rgba(255, 255, 255, 0.88)` | `rgba(25, 27, 32, 0.85)` |
| 次级表面 | `rgba(241, 243, 245, 0.65)` | `rgba(25, 27, 32, 0.60)` |
| 毛玻璃边框 | `rgba(255, 255, 255, 0.55)` / 微光内高光 | `rgba(255, 255, 255, 0.10)` |
| 分隔线 | `#e4e7ec` | `#23262e` |
| 正文 | 13px，系统字体 | 同左 |
| 主标题 | 18px／600 | 同左 |
| 圆角 | 控件 8px，卡片/面板 14px，封面 12px，胶囊/徽章 999px | 同左 |

强调色沿用现有调色板及自定义配色，按钮文字与强调文字继续计算对比度。成功、警告、失败使用各自语义颜色，并保留文字或图标说明；数字与音频参数使用等宽排版。

## 页面与导航

- 桌面侧栏宽 232px，折叠后 76px；601–800px 使用 72px 图标轨；600px 以下保留四项底部导航。导航项采用发光圆角胶囊指示器，快捷入口复用现有 URL，侧栏中部独立滚动，品牌与账户保持可见。
- 标题栏采用浮动毛玻璃设计，标题与操作位于统一行，语言、主题与配色在右上角毛玻璃面板展开。音乐库的浏览切换采用圆角胶囊分段控制（Segmented Control）、搜索框采用胶囊轮廓；桌面搜索使用受限宽度，窄屏占满可用空间。
- 概览以四个 Bento 式指标卡、完成度、活动曲目及近期任务组成工作区，卡片悬浮带有微动上浮反馈（`translateY(-2px)`）和柔和辉光，歌词、存储与注意事项采用毛玻璃面板层级。后台存储检查与离线提示留在存储面板。
- 任务采用紧凑列表，运行中任务突出进度，详情在原行下展开为内嵌毛玻璃检查区，保留结果、日志、分页、筛选和任务控制。
- 专辑、歌手封面采用 12px 优雅圆角，悬浮带轻微阴影扩展。异常短标签在封面左下，完整状态供辅助技术读取；最小密度下仍保持可读，选择框与标签不重叠。多选操作激活底部浮动胶囊批量操作栏（`.selection-bar`）。
- 歌曲行展示时长、音频规格、码率、源／产物大小、音频与歌词状态。完整路径、哈希与标签留在行内详情；标题区收紧并省略长歌名，详情正文保留全文。
- 试听使用内嵌毛玻璃播放器，桌面控制与歌词并排，窄屏上下排列。保留实际音频播放、进度滑块、歌词定位、当前行跟随及独立歌词滚动。
- 歌词候选与预览分栏，手机独立页面保留候选与预览分区滚动。短屏限制搜索说明高度，为候选保留至少 96px，并让预览与保存操作始终可达。
- 设置分类和表单使用毛玻璃面板。窄屏分类横向排列，字段上下堆叠；草稿、校验、保存与放弃行为沿用原有实现。保存栏采用底部吸附的浮动毛玻璃胶囊（`.settings-save`），常态贴合、变更时吸附置顶并显示高光状态。

## 可访问性与兼容

保留键盘访问、焦点环、Escape 关闭与焦点恢复、单选及部分选择状态、减少动态效果、强制颜色模式和安全区。手机歌曲、歌词、详情与保存操作至少保留 40px 触控高度，文本输入使用 16px 字体以避免自动缩放。

以已发布 `v0.2.50`（`bc3ff46`）为兼容基线。本轮不修改依赖、API、认证、Settings JSON、浏览器存储、歌词维护规则、任务格式或 schema 2；新增 JSX 结构仍按仓库的保守分类器决定验收范围。

## 验收与测试流程

测试流程完全依托 GitHub Actions 标准 CI 管道及原生测试工具，不使用任何 ponytail 依赖或标记：
1. **轻量门禁检测**：执行 `python3 -m unittest discover -s .github/scripts -p 'test_*.py' -v` 验证 CI 范围分类器与回滚判定逻辑。
2. **UI 快速路径判定**：`check-ui-scope.mjs` 基于 Rolldown AST 校验 TSX 语法不变性，CSS 与静态表现调整判定为 UI 范围。
3. **Playwright 浏览器测试**：CI 自动选择 Chromium 运行 `appearance.spec.ts`、`workspace-layout.spec.ts`、`library-experience.spec.ts`、`ui-refinement.spec.ts` 等既有测试用例，覆盖桌面与窄屏、暗色与浅色、双语及各核心操作流。
4. **代码纯净度**：所有测试与分类流程保持整洁，无内部冗余标记。
