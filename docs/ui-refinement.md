# MusicForge UI · Studio

本轮采用受 Linear 启发的简洁工作区：浅灰画布、白色表面、细描边、克制阴影和紧凑排版。当前实现以 [样式源文件](../web/src/style.css) 和 GitHub Actions 的实际页面截图为准。[Flat Studio 预览](ui-refinement-preview.html) 保留为历史设计资料，不再作为本轮像素对照基准。

## 视觉规则

| 项目 | 浅色 | 深色 |
| --- | --- | --- |
| 画布 | `#f8f9fa` | `#0b0c0e` |
| 主要表面 | `#ffffff` | `#121317` |
| 次级表面 | `#f1f3f5` | `#191b20` |
| 分隔线 | `#e4e7ec` | `#23262e` |
| 正文 | 13px，系统字体 | 同左 |
| 主标题 | 18px／600 | 同左 |
| 圆角 | 控件 6px，面板与封面 8px | 同左 |

强调色沿用现有调色板及自定义配色，按钮文字与强调文字继续计算对比度。成功、警告、失败使用各自语义颜色，并保留文字或图标说明；数字与音频参数使用等宽排版。

## 页面与导航

- 桌面侧栏宽 232px，折叠后 76px；601–800px 使用 72px 图标轨；600px 以下保留四项底部导航。快捷入口复用现有 URL，侧栏中部独立滚动，品牌与账户保持可见。
- 标题与操作位于统一的表面标题栏，语言、主题与配色仍在右上角展开。音乐库的浏览切换、搜索和视图选项保持清晰分组；桌面搜索使用受限宽度，窄屏占满可用空间。
- 概览以四个指标卡、完成度、活动曲目及近期任务组成工作区，歌词、存储与注意事项采用同一面板层级。后台存储检查与离线提示留在存储面板。
- 任务采用紧凑列表，运行中任务突出进度，详情在原行下展开为内嵌检查区，保留结果、日志、分页、筛选和任务控制。
- 专辑、歌手封面保持无外框的网格结构。异常短标签在封面左下，完整状态供辅助技术读取；最小密度下仍保持可读，选择框与标签不重叠。
- 歌曲行继续展示时长、音频规格、码率、源／产物大小、音频与歌词状态。完整路径、哈希与标签留在行内详情；标题区收紧并省略长歌名，详情正文保留全文。
- 试听使用内嵌播放器，桌面控制与歌词并排，窄屏上下排列。保留实际音频播放、进度滑块、歌词定位、当前行跟随及独立歌词滚动。
- 歌词候选与预览分栏，手机独立页面保留候选与预览分区滚动。短屏限制搜索说明高度，为候选保留至少 96px，并让预览与保存操作始终可达。
- 设置分类和表单使用表面面板。窄屏分类横向排列，字段上下堆叠；草稿、校验、保存与放弃行为沿用原有实现。保存栏显示在底部导航上方。

## 可访问性与兼容

保留键盘访问、焦点环、Escape 关闭与焦点恢复、单选及部分选择状态、减少动态效果、强制颜色模式和安全区。手机歌曲、歌词、详情与保存操作至少保留 40px 触控高度，文本输入使用 16px 字体以避免自动缩放。

以已发布 `v0.2.50`（`bc3ff46`）为兼容基线。本轮不修改依赖、API、认证、Settings JSON、浏览器存储、歌词维护规则、任务格式或 schema 2；新增 JSX 结构仍按仓库的保守分类器决定验收范围。

## 验收

本地只做源码、文档链接及空白检查。安装、类型检查、构建、浏览器验证、安全审计及其他选中门禁全部在 GitHub Actions 执行，不手动覆盖 CI 分类。

复用现有外观、工作区、试听、歌词、音乐库、任务和设置检查，保留密度、音频、触控、焦点、草稿、会话恢复及分页保证。删除仅针对历史预览的样式比较，将重复视口／语言／主题组合缩减为桌面、平板与窄屏代表场景，并保存实际页面截图供人工复核。
